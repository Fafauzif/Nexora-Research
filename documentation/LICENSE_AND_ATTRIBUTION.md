# Source licenses, attribution and modifications

This package combines independently licensed sources. It does not grant a new blanket license over their contents. Retain the source attribution and source-specific conditions when reusing or redistributing files. Metadata license declarations are preserved as supplied by the dataset hosts; the collection does not adjudicate rights held by original platform users.

Source publication dates, curator names, versions and metadata responses are in each dataset's metadata folder. Use those creator records when constructing formal references. Source discovery candidates excluded for unresolved redistribution or inadequate relevance are documented separately and contribute no corpus rows.

Original raw archives may contain public source author fields or personal details embedded in free text. The clean schemas reduce some identifiers or use pattern redaction where stated, but are not certified anonymized datasets. No credentials, browser sessions, private conversations or personal account access are included in this package.
